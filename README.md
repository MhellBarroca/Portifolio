# Portfólio Profissional

Site de portfólio com pipeline CI/CD no GitHub Actions.

- **CI:** valida todo Pull Request para a `main` (index.html, linter, tamanho de arquivos, varredura de texto e links/imagens).
- **CD:** publica automaticamente no GitHub Pages a cada push na `main`.

Site online: https://mhellbarroca.github.io/Portifolio/
